# Виджет EKT

React + Shadow DOM. Стили включены внутрь одного JS-файла.

Сборка: `npm run build:widget` → `dist-widget/widget.js`.
Разместите файл на своём сервере и подключите:

```html
<script defer src="/widget.js" data-ekt-widget data-api-base="https://your-backend.example"></script>
```

Адрес — пример, замените реальным backend. Без data-api-base работает демонстрация.
Для сайта HTTPS backend тоже должен быть HTTPS и разрешать CORS для адреса сайта.
Секреты EKT во frontend не передаются.

Витрина при `npm run dev` автоматически монтирует виджет с VITE_API_URL.
При отдельной сборке адрес задаётся только data-api-base.
Повторный вызов не создаёт дубликат. ID ekt-ai-chat зарезервирован для виджета.

Работает: открытие, закрытие, Escape, возврат фокуса на кнопку,
мобильное окно, история до перезагрузки, загрузка, ошибки, повтор поиска,
карточки из GET /api/search?q=...

Это пока поиск по каталогу, а не интеграция AI: backend ещё не предоставляет
маршрут чата. Для вложений готовы выбор, проверка расширения/размера,
превью JPEG, имя документа и удаление. Временный лимит — 10 МБ,
его нужно согласовать с backend. Проверка расширения не заменяет
серверную проверку содержимого. Отправка заблокирована при выбранном
вложении: endpoint загрузки ещё отсутствует, файл не передаётся.
Корзина: POST /api/cart/add с query-параметрами product_id и quantity
вызывается только кнопкой «Да, добавить». Количество проверяется по
известному остатку; окончательную проверку выполняет backend.
Корзина сервера общая для всех клиентов, ссылки на checkout пока нет.
После потери ответа автоматического повтора нет: добавление не идемпотентно.
Неизвестные цены и наличие не подменяются выдуманными значениями.
