# Frontend

Запуск из корня репозитория: `npm install`, затем `npm run dev`.
Проверка сборки: `npm run build`.

Без VITE_API_URL работает деморежим: фиксированные тестовые товары,
локальная корзина. Заказ не отправляется в магазин.

Для подключения создайте `.env.local` с `VITE_API_URL=http://localhost:8000`
и перезапустите Vite. Backend должен разрешить CORS для адреса frontend.
Никаких секретных ключей в переменных VITE_*: они доступны браузеру.

Предлагаемый контракт (нужно согласовать с backend):
POST /api/chat, JSON: {"message":"Автомат на 16 А","session_id":"uuid"}.
Ответ: {"message":"Найден товар","products":[{"id":"123","name":"Автомат","price":2500,"available":true}]}.
id — строка, price — неотрицательное число в тенге, available — boolean.
products обязателен, для ответа без товаров используйте []. sku необязателен.
Ошибки возвращаются с HTTP-статусом вне 200–299.

Сессия сохраняется на вкладку, корзина — на браузер и адрес backend.
Демо-корзина отделена от корзины реального API. Корзина пока локальная:
ее серверные маршруты и оформление заказа требуют отдельного согласования.

Проверка вручную: пустая отправка заблокирована; запрос показывает загрузку;
отмена добавления не меняет корзину; подтверждение добавляет одну единицу;
количество и итог пересчитываются; обновление сохраняет корзину;
недоступный товар нельзя добавить. В режиме API проверьте отключенный сервер,
HTTP-ошибку и некорректный ответ — сообщение можно повторить.
